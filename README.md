# AI Safety Dashboard

MediaPipe Pose 기반 작업자 안전 모니터링 Streamlit 대시보드입니다.

## 주요 기능
- 예제 실험 결과 자동 표시
- CSV 업로드 및 분석
- 전체 프레임 / 위험구역 진입 / CAUTION / DANGER 요약
- 동작별 DANGER 비율 시각화
- Baseline 대비 제안 방법 비교
- 결과 해석 및 연구 한계 안내

## 실행 파일
- `app.py`: Streamlit 메인 앱
- `requirements.txt`: 필요한 Python 패키지
- `sample_data.csv`: 예제 실험 결과

## 실행 방법
```bash
streamlit run app.py
```

본 앱은 수업 과제를 위해 제작한 학습용 프로토타입이며 실제 산업재해 예측 시스템이 아닙니다.
